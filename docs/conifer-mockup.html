Tap the cloud icon in the app bar any time for sync details (debug) - device id, last sync, pending changes, last error.

Double-click a card (or ⋮ → Edit) to edit in place; the copy icon on a day header exports that day as markdown. The 🌙 toggle previews the dark theme on every platform. The cloud icon in the app bar opens sync settings — entirely optional, off by default, and shows a live syncing state plus a debug details panel once connected. Desktop and Web can switch to a two-pane layout with a day sidebar; the real app now has that layout too, driven by the window's Material size class rather than by the platform.
